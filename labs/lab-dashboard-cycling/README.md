# Cycling Weather Dashboard

Interactive dashboard built with Python and Vizro to visualize weather conditions for cycling.

## Technologies

- Python 3.12
- uv
- Vizro
- Plotly
- Docker
- Open-Meteo API
- Render

## Features

- Weather forecast
- City filter
- Date filter
- Automatic retry for API rate limits
- Local snapshot fallback
- Dockerized deployment
